# Milestone 0.7 — Continuity tools

Status: **active; timeline format, calendar arithmetic, and source-linked derivation are complete**

The approved fact format and compatibility boundary live in [`../CONTINUITY_FORMAT.md`](../CONTINUITY_FORMAT.md). The approved timeline/calendar contract and schema live in [`../TIMELINE_FORMAT.md`](../TIMELINE_FORMAT.md). Existing projects remain valid and are never migrated on open or index refresh.

## Outcome

The app provides science-fiction-specific reasoning tools that trace every warning back to facts the writer controls.

## Planned slices

### Typed world facts

- [x] Review and approve the portable fact boundary before changing project metadata or app behavior.
- [x] Publish a versioned schema and safely parse/index optional canon and typed facts without rewriting notes.
- [x] Document built-in property semantics and inspect active-note facts read-only with exact source and reference links.
- [x] Add guarded authoring for documented properties across people, places, factions, technology, species, spacecraft, events, scenes, and chapters.
- [x] Support `idea`, `draft`, `canon`, and `retired` status without hiding uncertain material.
- [x] Keep unknown and intentionally contradictory facts representable.

### Time

- [x] Inventory existing time sources, research standards and writing-tool conventions, and draft the portable timeline/calendar contract without changing a project format.
- [x] Approve the timeline/calendar file, fictional-calendar subset, track identity, and deterministic ordering semantics.
- [x] Publish the version-one JSON Schema and safely parse the optional file without loading, creating, or rewriting it.
- [x] Normalize Gregorian, fixed-calendar, and ordinal expressions into deterministic ranges.
- [x] Derive source-linked timeline subjects, ambiguity states, tracks, and narrative context in memory.
- [ ] Load the optional project timeline file read-only and expose a source-linked timeline workspace.
- Build world and story timelines with parallel tracks and eras.
- Support a documented project calendar before attempting fictional calendars.
- Calculate character age at an event when dates are sufficiently known.
- Flag impossible or uncertain appearances with source links and confidence explanations.

### Space and travel

- Represent locations and writer-defined travel models.
- Calculate departure, duration, and arrival ranges without assuming a universal fictional propulsion model.
- Distinguish exact values, estimates, and unknowns.
- Link results back to the source facts used.

### Relationships and maps

- Represent typed character and faction relationships with time bounds where useful.
- Provide focused relationship views rather than an unreadable global graph.
- Attach project-owned map images and link notes/events to points or regions.
- Keep maps optional and portable.

### Continuity review

- Run deterministic checks for chronology, presence, canon status, conflicting properties, unresolved links, and selected manuscript claims.
- Report findings as reviewable evidence, not automatic truth.
- Allow intentional exceptions with an explanation.

### Optional assistance exploration

- Evaluate whether AI adds value beyond deterministic checks.
- Require explicit opt-in, provider/data disclosure, and a separate implementation decision.
- Never make network access a prerequisite for continuity tools.

## Milestone exit criteria

- Timeline, age, travel, and relationship tools operate on documented portable data.
- Every continuity finding links to the facts and rule that produced it.
- Uncertain or fictional physics is represented honestly.
- No manuscript content leaves the machine during the core workflow.
