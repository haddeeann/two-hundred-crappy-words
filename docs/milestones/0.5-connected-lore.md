# Milestone 0.5 — Connected lore

## Outcome

A writer can move between prose and world knowledge quickly, see how facts are connected, and keep a reference open without losing the manuscript context.

## Planned slices

### Project index

- Index Markdown paths, titles, aliases, headings, links, and selected properties.
- Update incrementally after app and external filesystem changes.
- Exclude app metadata, hidden files, generated output, and configured paths.
- Remain responsive on a representative large project.

### Links and backlinks

- Parse and render `[[Note]]`, `[[Note|label]]`, and heading links with documented escaping rules.
- Complete note names from the keyboard while typing.
- Show outgoing links and source-context backlinks.
- Identify useful unlinked mentions without overwhelming the writer.
- Surface broken and ambiguous links.

### Search and navigation

- Add fast title/content search with understandable ranking.
- Add a keyboard-first quick opener.
- Preserve the manuscript selection when consulting lore.
- Support navigation history.

### Reference pane

- Open a linked note beside the active document.
- Make reference mode clearly read-only or explicitly editable.
- Provide a fast path to create a missing linked note.
- Handle link-target rename through a previewed, recoverable update.

## Milestone exit criteria

- A writer can create, follow, search, and trace links across a realistic project.
- External edits are reflected without a full restart.
- Rename and broken-link behavior are safe and tested.
- Typing and navigation remain responsive under the performance fixture.
